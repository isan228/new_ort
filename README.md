# ОРТ 2026

Платный тренажёр ОРТ для школьников Кыргызстана: банки вопросов, конструктор теста по темам и навыкам, связанные вопросы (чтение), flashcards, история, глоссарий, админка и TXT-загрузки.

Стек: **Node.js + Express + Sequelize + PostgreSQL** и **React (Vite)**. Без Docker. API сразу пригодно для будущего мобильного клиента.

## Как устроено (USMLE → ОРТ)

| Было (USMLE) | Стало (ОРТ) |
|---|---|
| Step 1 / 2 / 3 | `trackGroup`: `main` / `state_lang` / `subject` |
| Subject × System теги | Тема × Навык (`topic` / `skill`) |
| `usmleSubscriptionEndDate` | `subscriptionEndDate` |
| `/api/tests/usmle/*` | `/api/tests/ort/*` |
| MedicalImage | TermImage (школьные термины) |
| `universityId` | нет — продукт только про ОРТ |

Подписка одна на весь раздел. Контент не привязан к вузу.

Треки:

1. **Основной тест** — математика, аналогии, чтение, грамматика.
2. **Государственный язык** — обязательный кыргызский.
3. **Предметные** — химия, биология, физика, математика, история, английский и др.

## Запуск локально

1. Установите PostgreSQL (служба должна быть запущена).

2. Поставьте зависимости и дайте скрипту самому создать базу, таблицы и сиды:

```bash
npm install
npm run install:all
npm run setup:db
```

Если пароль суперпользователя не `postgres` (PowerShell):

```bash
$env:POSTGRES_PASSWORD="твой_пароль"; npm run setup:db
```

Скрипт при отсутствии скопирует `.env` из `.env.example`, создаст пользователя и базу из `DATABASE_URL`, накатит схему и демо.

3. Запуск:

```bash
npm run dev
```

- API: http://localhost:4000  
- Сайт: http://localhost:5173  

При старте сервер сам синхронизирует схему, посеет теги, тарифы, админа, демо-ученика и демо-банки.

Демо-логины:

- ученик с подпиской: `demo@ort.kg` / `demo123`
- админ: `admin@ort.kg` / `admin123`

Оплата на `/subscriptions` сейчас демо: создаёт платёж `ort_subscription` и сразу продлевает дату. Позже подключите шлюз к `POST /api/payments/webhook`.

## TXT для админки

Поле файла: **`pdf`** (или `file`).

Вопросы:

```
"ID":"101"
"Q":"Текст"
"A1":"вариант"
"A2":"вариант"
"A3":"вариант"
"A4":"вариант"
"Correct":"2"
"E":"Объяснение"
"Topic":"Алгебра"
"Skill":"Вычисление"
```

Связанные (один `GroupID` = один текст):

```
"GroupID":"1"
"ID":"201"
"Q":"..."
```

Карточки:

```
=== Проценты и доли ===
"ID":"1"
"Front":"Чтобы найти p% от a, нужно ______"
"Back":"a × p / 100"
```

Примеры лежат в `server/data/`.
